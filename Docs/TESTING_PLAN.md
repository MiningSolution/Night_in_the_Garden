## 🔴 P0 - CRITICAL PRIORITY TESTS

### P0-1: Server-Side Tool Validation Security

**Цель:** Проверить, что клиент не может использовать несуществующие инструменты

**Тесты:**

1. **Тест 1.1: Валидация инструмента на сервере**
   - **Шаги:**
     1. Игрок экипирует инструмент через HotbarController
     2. Отправить InteractWithPlot с поддельным toolName ("AdminTool", "SuperHarvest")
     3. Проверить, что сервер игнорирует clientToolName и использует server state
   - **Ожидаемый результат:** Сервер использует реальный экипированный инструмент, не поддельный
   - **Проверка:** В консоли должно быть предупреждение о несоответствии

2. **Тест 1.2: Попытка использовать инструмент без владения**
   - **Шаги:**
     1. Игрок НЕ имеет "improved_watering_can" в инвентаре
     2. Попытаться экипировать "improved_watering_can" через EquipTool
   - **Ожидаемый результат:** Экипировка отклонена, инструмент не установлен
   - **Проверка:** В консоли предупреждение о неудачной валидации

3. **Тест 1.3: Синхронизация экипировки**
   - **Шаги:**
     1. Игрок экипирует инструмент через HotbarController
     2. Проверить, что EquipTool событие отправлено на сервер
     3. Использовать инструмент на грядке
   - **Ожидаемый результат:** Сервер использует правильный инструмент из InventoryService
   - **Проверка:** Взаимодействие работает корректно

---

### P0-2: Quantity Validation in Shop System

**Цель:** Проверить строгую валидацию количества перед операциями

**Тесты:**

1. **Тест 2.1: Валидация отрицательных чисел**
   - **Шаги:**
     1. Попытаться купить товар с quantity = -5
   - **Ожидаемый результат:** Ошибка "Quantity must be positive"
   - **Проверка:** Покупка отклонена

2. **Тест 2.2: Валидация NaN/Infinity**
   - **Шаги:**
     1. Попытаться купить товар с quantity = math.huge
     2. Попытаться купить товар с quantity = 0/0 (NaN)
   - **Ожидаемый результат:** Ошибка "Invalid quantity value"
   - **Проверка:** Покупка отклонена

3. **Тест 2.3: Валидация нецелых чисел**
   - **Шаги:**
     1. Попытаться купить товар с quantity = 5.7
   - **Ожидаемый результат:** Ошибка "Quantity must be an integer"
   - **Проверка:** Покупка отклонена

4. **Тест 2.4: Валидация превышения лимита**
   - **Шаги:**
     1. Попытаться купить товар с quantity = 1000 (больше 999)
   - **Ожидаемый результат:** Ошибка "Quantity too large (max: 999)"
   - **Проверка:** Покупка отклонена

5. **Тест 2.5: Валидация неверного типа**
   - **Шаги:**
     1. Попытаться купить товар с quantity = "abc"
     2. Попытаться купить товар с quantity = {}
   - **Ожидаемый результат:** Ошибка валидации
   - **Проверка:** Покупка отклонена

### P0-3: Atomic Item Consumption

**Цель:** Проверить отсутствие race conditions при потреблении предметов

**Тесты:**

1. **Тест 3.1: Быстрая посадка на несколько грядок**
   - **Шаги:**
     1. Игрок имеет 1 семя "carrot_seed"
     2. Быстро кликнуть на 2 разные грядки одновременно (или почти одновременно)
   - **Ожидаемый результат:** Только одна грядка посажена, вторая отклонена с ошибкой "No seeds"
   - **Проверка:** В инвентаре 0 семян, только одна грядка в состоянии "Planted"

2. **Тест 3.2: Нормальная посадка**
   - **Шаги:**
     1. Игрок имеет 5 семян "carrot_seed"
     2. Посадить семя на грядку
   - **Ожидаемый результат:** Грядка посажена, в инвентаре осталось 4 семени
   - **Проверка:** Инвентарь обновлен корректно

### P0-4: PlantGrowthService Memory Leak Fix

**Цель:** Проверить защиту от множественных запусков

**Тесты:**

1. **Тест 4.1: Защита от двойного запуска**
   - **Шаги:**
     1. В консоли сервера вызвать `PlantGrowthService.Start()` дважды
   - **Ожидаемый результат:** Второй вызов игнорируется с предупреждением "Already running!"
   - **Проверка:** В консоли предупреждение, только один цикл работает

2. **Тест 4.2: Корректная остановка**
   - **Шаги:**
     1. Вызвать `PlantGrowthService.Stop()`
     2. Проверить, что цикл остановлен
   - **Ожидаемый результат:** Цикл остановлен, в консоли сообщение "Stopped"
   - **Проверка:** Растения больше не обновляются

3. **Тест 4.3: Автоматический запуск**
   - **Шаги:**
     1. Перезапустить сервер
     2. Проверить, что PlantGrowthService запустился автоматически
   - **Ожидаемый результат:** Сервис запущен, растения растут
   - **Проверка:** Растения обновляются каждую секунду

3. **Тест 5.3: Ошибка в клиентских event handlers**

### P1-2: Unified State Manager

**Цель:** Проверить работу StateManager и синхронизацию данных

**Тесты:**

1. **Тест 2.1: Подписка на изменения валюты**
   - **Шаги:**
     1. Изменить валюту через ClientDataCache.UpdateCurrency
     2. Проверить, что UIController автоматически обновил UI
   - **Ожидаемый результат:** UI обновлен без прямого вызова UIController.UpdateCurrency
   - **Проверка:** Валютные метки обновлены

2. **Тест 2.2: Подписка на изменения инвентаря**
   - **Шаги:**
     1. Изменить инвентарь через ClientDataCache.UpdateInventory
     2. Проверить, что InventoryController автоматически обновил grid
   - **Ожидаемый результат:** Grid обновлен без прямого вызова InventoryController.UpdateInventory
   - **Проверка:** Слоты инвентаря обновлены

3. **Тест 2.3: Применение snapshot**
   - **Шаги:**
     1. Вызвать ClientDataCache.RequestFullSync
     2. Проверить, что все данные синхронизированы
   - **Ожидаемый результат:** Все контроллеры получили обновления через StateManager
   - **Проверка:** UI показывает актуальные данные

4. **Тест 2.4: Иммутабельность состояния**
   - **Шаги:**
     1. Получить состояние через StateManager.getState()
     2. Изменить полученное состояние
     3. Получить состояние снова
   - **Ожидаемый результат:** Второе получение возвращает исходное состояние (не измененное)
   - **Проверка:** Deep copy работает корректно

### P1-3: Server-Side Cooldowns

**Цель:** Проверить защиту от спама взаимодействий

**Тесты:**

1. **Тест 3.1: Cooldown на взаимодействие**

     1. Быстро кликнуть на грядку 2 раза подряд (менее 0.5 секунды)

   - **Проверка:** В консоли сообщение о cooldown

2. **Тест 3.2: Cooldown per plot**
   - **Шаги:**
     1. Кликнуть на Plot1
     2. Сразу кликнуть на Plot2
   - **Ожидаемый результат:** Оба взаимодействия обработаны (cooldown per plot)
   - **Проверка:** Обе грядки обработаны

3. **Тест 3.3: Cooldown истекает**
   - **Шаги:**
     1. Кликнуть на грядку
     2. Подождать 0.6 секунды
     3. Кликнуть снова
   - **Ожидаемый результат:** Второй клик обработан успешно
   - **Проверка:** Взаимодействие работает

### P1-4: InventoryController Optimization

**Цель:** Проверить инкрементальные обновления grid

**Тесты:**

1. **Тест 4.1: Обновление существующего слота**
   - **Шаги:**
     1. Открыть инвентарь
     2. Изменить количество предмета (например, carrot_seed: 5 → 10)
     3. Проверить, что слот обновлен, а не пересоздан
   - **Ожидаемый результат:** Слот обновлен, количество изменено, слот не уничтожен
   - **Проверка:** В консоли "incremental update", слот существует

2. **Тест 4.2: Добавление нового предмета**
   - **Шаги:**
     1. Открыть инвентарь
     2. Добавить новый предмет в инвентарь
   - **Ожидаемый результат:** Создан новый слот, существующие слоты не затронуты
   - **Проверка:** Новый слот появился, старые остались

3. **Тест 4.3: Удаление предмета**
   - **Шаги:**
     1. Открыть инвентарь
     2. Удалить предмет из инвентаря (количество = 0)
   - **Ожидаемый результат:** Слот удален, остальные слоты не затронуты
   - **Проверка:** Слот исчез, остальные остались

4. **Тест 4.4: Производительность при большом инвентаре**
   - **Шаги:**
     1. Добавить 50+ предметов в инвентарь
     2. Обновить инвентарь
   - **Ожидаемый результат:** Обновление быстрое, нет лагов
   - **Проверка:** FPS не падает, обновление мгновенное

### P1-5: Anti-Cheat Logging System

**Цель:** Проверить логирование подозрительных действий

**Тесты:**

1. **Тест 5.1: Логирование неверного инструмента**
   - **Шаги:**
     1. Отправить InteractWithPlot с поддельным toolName
   - **Ожидаемый результат:** В консоли лог [ANTICHEAT][SUSPICIOUS] с деталями
   - **Проверка:** Лог содержит userId, username, event, details

2. **Тест 5.2: Логирование distance exploit**
   - **Шаги:**
     1. Попытаться взаимодействовать с грядкой с большого расстояния (>25 studs)
   - **Ожидаемый результат:** В консоли лог [ANTICHEAT][SUSPICIOUS] DISTANCE_EXPLOIT
   - **Проверка:** Лог содержит расстояние и максимальное разрешенное

3. **Тест 5.3: Логирование больших покупок**
   - **Шаги:**
     1. Купить товар с quantity > 100
   - **Ожидаемый результат:** В консоли лог [ANTICHEAT][INFO] LARGE_PURCHASE
   - **Проверка:** Лог содержит детали покупки

4. **Тест 5.4: Получение логов игрока**
   - **Шаги:**
     1. Вызвать AntiCheat.getPlayerLogs(userId)
   - **Ожидаемый результат:** Возвращается массив логов для игрока
   - **Проверка:** Логи содержат правильные данные

## 📝 ЗАМЕТКИ ПО ТЕСТИРОВАНИЮ

1. **Тестирование в Roblox Studio:**
   - Использовать TestService для автоматизации
   - Проверять консоль на ошибки и предупреждения

   - Отслеживать ошибки через RemoteHandlers

   - Нужно тестировать с реальными игроками для полной проверки
